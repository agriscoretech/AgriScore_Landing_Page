# 🌱 AgriScore Platform

> **Precision Agriculture for Sustainable Estates & High-Yield Farming**  
> *Redefining agricultural intelligence with soil analytics, toxin-free farming, and precision yield engineering.*

---

## 🌾 Overview

**AgriScore** is a modern, high-performance web platform designed to empower farmers, agricultural estates, and agronomy researchers. Rooted in real-world agricultural challenges, AgriScore delivers actionable soil intelligence, precision monitoring, and sustainable farming insights to reduce chemical dependencies, optimize yield, and protect soil health.

---

## ✨ Key Features

- **🌱 Soil & Crop Intelligence**: Comprehensive soil analytics, health scoring, and nutrient monitoring.
- **🛰️ Remote Sensing & NDVI Mapping**: Integration-ready field moisture and vegetation index tracking.
- **🧪 Sustainable Farming Insights**: Data-driven strategies for pesticide reduction and eco-friendly farming.
- **📈 Yield Engineering & Analytics**: Interactive charts and data visualizations powered by Recharts.
- **🎨 Modern, Responsive UI**: Crafted with Next.js App Router, Tailwind CSS, Radix UI, and fluid Framer Motion animations.
- **📱 Mobile-First Experience**: Optimized across smartphones, tablets, and desktop workstations.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: `v18.17.0` or higher
- **Package Manager**: `npm`, `yarn`, `pnpm`, or `bun`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/agriscoretech/AgriScore_Landing_Page.git
   cd AgriScore_Landing_Page
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.
